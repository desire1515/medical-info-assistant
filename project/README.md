# Intelligent Medical Information Assistant

This is the working, browser-only rule-based assistant. Select symptoms or warning signs and a duration to receive a general next-step recommendation with an explanation of the matching rule.

## Run locally

Open `index.html` in a modern browser. No installation, build step, backend, or server is required. Use “← Back to Portfolio” to return to the project presentation.

## Safety disclaimer

This tool provides general health information only. It does not diagnose, prescribe, or replace advice from a qualified health worker. Emergency warning signs should be assessed urgently; seek care at the nearest health facility and do not delay care to use this tool. Selections are not stored or sent.
